# AIプロンプト手法プレイブック

このページは、画像生成・動画生成・文章生成に共通するプロンプト設計の基本をまとめています。  
ポイントは「長く書くこと」ではなく、**誤読されない構造**にすることです。

## 基本フレーム（R-G-C-C-F）

- `Role`: どの専門家として振る舞うか
- `Goal`: 何を達成したいか
- `Context`: 背景情報と前提
- `Constraints`: 禁止事項・制約
- `Format`: 出力形式

```text
あなたは[Role]です。
目的は[Goal]です。
前提情報: [Context]
制約:
- [Constraint 1]
- [Constraint 2]
出力形式:
- [Format]
```

## 失敗しにくい書き方

1. 形容詞より条件を増やす  
2. 「何を避けるか」を明示する  
3. 出力の順番を指定する  
4. 検収条件を最後に置く

### 悪い例

```text
かっこいいアニメ風でいい感じに。
```

### 改善例

```text
目的: 15秒のティザー映像コンテ案を作る
制約:
- 夜の都市背景
- 主人公は1人、顔アップは2カット以内
- 暴力表現なし
出力:
1. 3カット構成
2. 各カットの画角、カメラ動作、感情
3. 1行の狙い
```

## 反復改善ループ

### 1st pass

- まずは大枠（構成）だけ出す

### 2nd pass

- ノイズを削る（余計な要素を除外）

### 3rd pass

- 一貫性を固定（色、時代、人物属性）

### 4th pass

- 出力テンプレートを固定して再利用

## プロンプト分割法

1本の長いプロンプトより、目的別に分割した方が安定します。

- Step A: 企画意図を定義
- Step B: 構図・ショットを定義
- Step C: ライティング・色を定義
- Step D: NG条件を定義

## よく使う制約テンプレ

```text
制約:
- 3カット以内
- 色は3色以内
- 1カット1情報
- 画面中央に被写体を置かない
- 背景情報を説明しすぎない
```

## チェックリスト

- 目的が1文で言えるか
- 禁止条件があるか
- 出力形式が明示されているか
- 成功条件があるか
- 次回再利用できる形か
