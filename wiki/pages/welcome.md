# Wikiへようこそ

このWikiは、`yohaku-0to1.github.io` の制作知識と運用ノウハウをまとめるための場所です。  
AIプロンプト手法、アニメ構図、照明設計、絵コンテ設計を中心に蓄積していきます。

## 使い方

- 左カラム: 記事一覧と検索
- 中央: 本文
- 右カラム: 現在記事の目次

## メモの書き方ルール

- 1トピック1見出しで書く
- なるべく具体的なファイルパスを載せる
- 作業コマンドはコードブロックで残す

```sh
git status -sb
git add -A
git commit -m "docs: update wiki note"
```
