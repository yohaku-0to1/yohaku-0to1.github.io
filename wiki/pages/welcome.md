# Wikiへようこそ

このWikiは、`yohaku-0to1.github.io` の開発・更新情報をまとめるための場所です。  
「どこを編集すれば何が変わるか」を、短く確認できるようにしています。

## 使い方

- 左カラム: 記事一覧と検索
- 中央: 本文
- 右カラム: 現在記事の目次

## まず読む記事

1. `サイト構成ガイド`
2. `コンテンツ更新手順`
3. `運用メモ`

## メモの書き方ルール

- 1トピック1見出しで書く
- なるべく具体的なファイルパスを載せる
- 作業コマンドはコードブロックで残す

```sh
git status -sb
git add -A
git commit -m "docs: update wiki note"
```
