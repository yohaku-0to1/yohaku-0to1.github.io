# アニメ映像設計体系（構図・ライティング・カメラ）

このページは、アニメ制作における「構図・光・カメラ」を、工程で使える設計変数として整理した統合ガイドです。  
劇場、TV、短編、フルCG、2Dセル風CGを同じ軸で扱えるようにしています。

## エグゼクティブサマリー

- 視線誘導は経験則だけでなく、サリエンシー（明暗・色・方向）で設計できる
- 画づくりの破綻は、工程間の受け渡し情報不足で起きることが多い
- 制作を安定させるには、`Cut ID + 構図 + 光 + カメラ + 制約` を最小単位で固定する
- ルック（セル/グラデ/PBR）の違いは、光モデルの違いとして先に明文化する

## 対象範囲（制約なし）

- 劇場アニメ
- TVアニメ
- 短編アニメ
- フルCGアニメ
- 2Dセル風CG（NPR/トゥーン）

## 形式別の実務差分

### 劇場

- 強み: 大画面で細部と空気感が伝わる
- 制約: 同じ移動でも体感速度が上がり、動きが強く見えやすい
- 設計ポイント: パン速度、移動幅、コマ打ち、ブラー量を慎重に設計する

### TVシリーズ

- 強み: 話数で見せ場を積み上げられる
- 制約: 撮影（コンポジット）工程の日数が短くなりやすい
- 設計ポイント: レイアウト段階で光効果とカメラ意図を先に固定して手戻りを減らす

### 短編

- 強み: コンセプトを尖らせやすい
- 制約: 実験と納期の両立
- 設計ポイント: カラースクリプトで感情曲線を先に確定する

### フルCG

- 強み: 回り込みや遠近変化などカメラ自由度が高い
- 制約: 線・陰影・ID管理が崩れるとルックが破綻しやすい
- 設計ポイント: レンダーレイヤーと線表現の最終仕様を先に定義する

### 2Dセル風CG

- 強み: 3D上でアニメ記号を再現しやすい
- 制約: しきい値、輪郭線、影境界の整合が難しい
- 設計ポイント: 2値化ルールと輪郭ルールをルック仕様として固定する

## 構図の体系

## 主要設計変数

- ショットサイズ: LS / MS / BS / CU / ECU
- カメラ角度: 俯瞰 / 仰視 / アイレベル / ダッチ
- 配置ルール: 三分割 / 中央配置 / 二分割
- 線の設計: 対角線 / 放射 / S字
- 対称性: シンメトリー / 崩し
- フレーミング: 額縁効果 / 前景フレーム
- 余白: 意味のあるネガティブスペース
- サリエンシー: 明暗差・色差・方向差

## 視線誘導の実務優先順位

1. 明暗コントラスト
2. 顔（特に目）
3. 動き
4. 色アクセント
5. テキスト情報

## 構図で破綻しやすい点

- 主題が複数あって視線が迷う
- 余白が意図ではなく空白になる
- カット間で目線方向が繋がらない
- 背景ディテールが主題を食う

## ライティングの体系

## 光源タイプと役割

- キーライト: 時間帯と主面の基準を作る
- フィルライト: 影情報を残すか潰すかを制御
- バック/リムライト: 背景からの分離を作る
- トップライト: 不穏・支配感など強い心理効果を出す
- 実用光（practical）: 空間説得力と物語情報を補強する

## 色温度とコントラスト

- 基準値の目安: 3200K（暖色側）/ 5600K（昼光側）
- 色温度はショットごとではなく、シーン単位でレール化する
- コントラストは段差で管理する（1段差=2:1, 2段差=4:1, 3段差=8:1）

## ルック別の光処理差

### セル調

- 明暗をしきい値で分割
- 影境界を記号として扱いやすい

### グラデ調

- 中間階調が主役
- 塗りと撮影の役割分担が曖昧だと破綻しやすい

### PBR

- 光学的整合は強い
- そのままでは“アニメ記号”が弱くなるため、スタイライズ制御が必要

## カメラワークの体系

## 基本運動と心理効果

- パン/ティルト: 空間関係を見せる
- ドリーIN/OUT: 没入と距離化を作る
- ズーム: 情報選択を強制する
- ドリーズーム: 不安、気づき、異常感
- 手ブレ: 主観性・不安定
- 回り込み: 空間の立体性と解放感

## レンズ・被写界深度・ブラー

- DOFは `F値 + 焦点距離 + 被写体距離` で決まる
- 望遠は浅いDOF、広角は深いDOFになりやすい
- モーションブラーはシャッター角度を基準に統一する

## カメラの存在感（作品思想）

- カメラを見せる演出: フレア、ブレ、収差を積極使用
- カメラを消す演出: 透明な視点で没入を優先
- 作品ごとにどちらを採るかを最初に決める

## よくあるトラブルと対処

### 撮影工程で要望が膨らむ

- 原因: 「後で何とかする」前提
- 対処: 必須効果と任意効果を分け、必須を先に固定

### セル風CGの線が弱い

- 原因: 線の最終仕様が未定義
- 対処: 線太さ、入り抜き、補正方法をルック仕様として文書化

### 立体視・特殊出力で手戻り

- 原因: 出力仕様確定が遅い
- 対処: プリ段で出力制約を固定し、修正可能域を先に決める

### 劇場で動きが強すぎる

- 原因: 画面サイズ差を見落とす
- 対処: 移動幅、コマ打ち、ブラーをセットで見直す

## 実務チェックリスト

- 主題は1秒以内に特定できるか
- 余白に意味があるか
- ショットサイズと目的が一致しているか
- 色温度レールが決まっているか
- キー/フィル/バックの役割が分かれているか
- ルック（セル/グラデ/PBR）が混在していないか
- カメラ種と速度カーブが明記されているか
- DOF意図が明確か
- ブラー基準がショット間で統一されているか
- 撮影打合せで必須効果が確定しているか
- 出力仕様がプリ段で確定しているか
