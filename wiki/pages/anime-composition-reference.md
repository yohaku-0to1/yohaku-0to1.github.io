# アニメ構図リファレンス

統合版は `アニメ映像設計体系（構図・ライティング・カメラ）` を参照。  
このページは「構図だけに絞った早見メモ」です。

構図は「何を見せるか」ではなく、**何を先に理解させるか**です。  
このページでは、制作中にすぐ参照できるように要点だけを整理します。

## ショットサイズの基本

| サイズ | 主目的 | 向いている場面 |
| --- | --- | --- |
| EWS（超ロング） | 空間・孤独・規模 | 導入、環境説明 |
| WS（ロング） | 動線・関係性 | アクション、移動 |
| MS（ミディアム） | 会話・状況 | 日常シーン |
| CU（アップ） | 感情・反応 | 心理変化、決断 |
| ECU（寄り） | 象徴・緊張 | 重要物、異変の強調 |

## 視線誘導の優先順位

1. 明暗コントラスト  
2. 顔（特に目）  
3. 動き  
4. 色差  
5. テキスト

## すぐ効く構図ルール

- 三分割に主被写体を置く  
- 進行方向に空間を残す  
- 視線先に余白を作る  
- 情報は前景/中景/背景の3層で整理  
- 画面端で切るときは「意味のある欠け方」にする

## 感情別の画面傾向

### 安心・平穏

- 水平・対称
- 中望遠
- 柔らかいグラデーション

### 不安・違和感

- 斜め線・片寄り
- 広角寄り
- コントラスト強め

### 圧迫・緊張

- 被写体をフレーム内で狭く囲う
- 手前オブジェクトで覗き見構図
- 逃げ場のない中央寄せ

## 1カット1情報の原則

1カットで伝える情報は1つに絞ります。

- 感情を見せるカットなら、背景情報は減らす
- 空間説明カットなら、顔の演技は最小限

## よくある崩れ方

- 情報を詰めすぎて主題が消える
- 寄り引きのリズムが単調
- 目線の向きがカット間で繋がらない
- 背景ディテールが感情演出を邪魔する

## カット作成時の最終確認

- 最初の1秒で主題が分かるか
- 視線の着地点が1つに絞れているか
- 次カットへ繋ぐ動機があるか
