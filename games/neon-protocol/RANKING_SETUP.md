# Neon Protocol - ランキングシステム セットアップガイド

## Google Apps Script (GAS) のセットアップ手順

ランキング機能を有効にするには、以下の手順でGoogle Apps Scriptをセットアップする必要があります。

### 1. Google スプレッドシートの作成

1. [Google スプレッドシート](https://sheets.google.com/)にアクセス
2. 新しいスプレッドシートを作成
3. シート名を「Rankings」に変更

### 2. Google Apps Script の設定

1. スプレッドシートのメニューから「拡張機能」→「Apps Script」をクリック
2. エディタが開いたら、既存のコード（`function myFunction() { ... }`）を全て削除
3. `gas/ranking-script.gs`の内容を全てコピーしてペースト
4. ツールバーの「プロジェクト設定」アイコン（歯車）をクリック
5. 「プロジェクト名」を「Neon Protocol Rankings」などに変更

### 3. スプレッドシートの初期化

1. エディタの上部にある関数選択ドロップダウンから `initializeSheet` を選択
2. 「実行」ボタン（▶）をクリック
3. 初回実行時、権限の承認を求められるので「権限を確認」→ アカウント選択 → 「詳細」→「安全ではないページに移動」→「許可」をクリック
4. 実行ログに「Sheet initialized successfully」と表示されれば成功

### 4. Web アプリとしてデプロイ

1. エディタ右上の「デプロイ」→「新しいデプロイ」をクリック
2. 「種類の選択」で「ウェブアプリ」を選択
3. 設定:
   - **説明**: 「Neon Protocol Rankings API」（任意）
   - **次のユーザーとして実行**: 「自分」
   - **アクセスできるユーザー**: 「全員」を選択
4. 「デプロイ」をクリック
5. 表示される「ウェブアプリURL」をコピー（例: `https://script.google.com/macros/s/*****/exec`）

### 5. ゲームにAPI URLを設定

1. `js/ranking.js` ファイルを開く
2. 2行目の `const RANKING_API_URL = 'YOUR_GAS_DEPLOYMENT_URL_HERE';` を編集
3. コピーしたウェブアプリURLに置き換え:
   ```javascript
   const RANKING_API_URL = 'https://script.google.com/macros/s/あなたのID/exec';
   ```
4. ファイルを保存

### 6. テスト

1. ゲームをプレイしてLayer 15をクリア
2. スコア送信画面が表示されることを確認
3. 名前を入力して「ランキングに登録」をクリック
4. Googleスプレッドシートの「Rankings」シートにデータが追加されることを確認

## トラブルシューティング

### ランキングが表示されない
- ブラウザのコンソール（F12）でエラーを確認
- GASのデプロイURLが正しく設定されているか確認
- スプレッドシートの共有設定を確認

### スコア送信が失敗する
- GASの「アクセスできるユーザー」が「全員」になっているか確認
- GASのログ（Apps Scriptエディタの「実行数」）でエラーを確認
- CORS エラーの場合、GASが正しくデプロイされているか確認

## スコア計算方式

```
総合スコア = Layer到達 × 1000 
           + 残りIntegrity × 10 
           + レリック数 × 200 
           + 進化ボーナス

進化ボーナス:
- 子供ネオン: 0
- 大人ネオン: 500
- ダークストリート/エレクトロマスター: 1500
- バーサーカー: 2000
```

## データ構造

スプレッドシートには以下のデータが保存されます:

| Name | Score | Layer | Phase | Timestamp |
|------|-------|-------|-------|-----------|
| プレイヤー名 | スコア | 到達Layer | 進化形態 | 日時 |
