Remotion 学習ガイド

Reactで動画を作るためのフレームワーク「Remotion」の基礎知識まとめ。

1. Remotionとは

Remotionは、動画編集ソフトを使わずに React (HTML/CSS/JavaScript) のコードを書いて動画を作成するフレームワークです。

  • 仕組み: Headless Chrome（ブラウザ）を裏で動かし、コマごとに描画した結果をFFmpegで結合して動画にします。
  • 特徴: プレビューが高速、データ連動（API/JSON）が得意、Gitでバージョン管理が可能。

2. 前提環境とセットアップ

2.1. 必須環境

  • Node.js: v16以上 (LTS推奨)
  • OS: macOS, Windows, Linux
  • FFmpeg: インストール不要（Remotion v4が内部で自動管理してくれます）。
    ※特殊な環境設定をしたい場合のみ手動インストールしますが、基本は不要です。

2.2. インストール手順

ターミナルでプロジェクトを作りたいフォルダへ移動し、以下を実行します。

npx create-video@latest

対話形式で設定を聞かれます。推奨設定は以下の通りです。

  • Project name: 任意の名前（例: my-video）
  • Template: Hello World (構成が最も分かりやすいため推奨)
  • Language: TypeScript (推奨) / JavaScript

3. 開発ワークフロー

3.1. プレビュー画面 (Studio) の起動

コードを書いている最中は、ブラウザ上のエディタ（Studio）で確認します。

npm run dev
  • ブラウザが自動で立ち上がります。
  • コードを保存すると、ブラウザをリロードしなくても即座に反映されます（Fast Refresh）。
  • ※もしコマンドが動かない場合は、一度 npm install を実行してください。

3.2. ファイル構成とアーキテクチャ

src フォルダ内の主要ファイルの関係性は以下の通りです。

src/
├── index.ts          # 【エントリーポイント】 Reactをマウントする場所（通常は編集不要）
├── Root.tsx          # 【マニフェスト】 動画全体の定義（FPS、サイズ、構成）
├── Composition.tsx   # 【コンポーネント】 動画の中身（UI構築を行うメインの場所）
└── HelloWorld/       # 部品となるコンポーネント群（タイトル、ロゴなど）

src/Root.tsx の詳細

動画の「設計図」です。ここで定義した id を書き出し時に使います。

<Composition
  id="HelloWorld"          // 👈 書き出しコマンドで指定するID
  component={HelloWorld}   // 👈 実際に表示するコンポーネント
  durationInFrames={150}   // 👈 動画の長さ（フレーム数）
  fps={30}                 // 👈 1秒あたりのフレーム数
  width={1920}             // 👈 解像度（幅）
  height={1080}            // 👈 解像度（高さ）
  defaultProps={{
    titleText: "Welcome",
  }}
/>

4. アニメーションの実装（Core Concepts）

Remotionにおけるアニメーションは、「時間（フレーム）」を「数値（スタイル）」に変換することで実現します。

4.1. 現在時刻の取得

useCurrentFrame() フックを使用します。

import { useCurrentFrame } from 'remotion';

const frame = useCurrentFrame(); 
// frame変数は、0, 1, 2... と動画の進行に合わせて増えていく

4.2. 基本アニメーション（Interpolate）

「フレーム 0〜30 の間に、不透明度を 0〜1 にしたい」といった制御には interpolate 関数を使います。

import { interpolate, useCurrentFrame } from 'remotion';

const frame = useCurrentFrame();

const opacity = interpolate(
    frame,
    [0, 30],  // 入力範囲 (フレーム数)
    [0, 1],   // 出力範囲 (不透明度)
    {
      extrapolateLeft: 'clamp',  // 0フレームより前は0のまま固定
      extrapolateRight: 'clamp', // 30フレームより後は1のまま固定
    }
);

return <div style={{ opacity }}>フェードインする文字</div>;

5. 動画の書き出しとコマンドの使い分け（重要）

Remotionには大きく分けて「動画ファイルを作るコマンド」と「Webアプリを作るコマンド」の2種類があります。目的に応じて使い分けます。

5.1. MP4動画を作る場合 (remotion render)

ローカルのPCで動画ファイル（.mp4）を生成したい場合は、このコマンドを使います。

npx remotion render <CompositionID> <出力ファイル名>

実行例:

npx remotion render HelloWorld out.mp4
【重要】Mac (Apple Silicon) ユーザー向けの注意点
M1 / M2 / M3 チップ搭載のMacを使っている場合、書き出し時にエラーが出たり画面が黒くなることがあります。その場合は --gl=angle オプションを付けてください。
npx remotion render HelloWorld out.mp4 --gl=angle

5.2. Webアプリとして書き出す場合 (npm run build)

package.json の build スクリプト（実体は remotion bundle）を実行した場合の挙動です。
MP4動画だけが欲しい場合は、この手順は不要です。 

npm run build
# または npx remotion bundle

生成されるものと使い道

このコマンドを実行すると、通常 out/ フォルダなどに以下のファイル群が生成されます。

  • 生成物: index.html, bundle.js, style.css など
  • 正体: これは動画ファイルではなく、「ブラウザで動画を再生するためのWebアプリケーション（静的サイト）」 です。
  • 主な使い道:
    1. Web公開: GitHub Pages, Vercel, Netlify, S3などにアップロードし、Web上で動画プレイヤーとして公開する。
    2. クラウドレンダリング: AWS Lambdaなどで大量の動画を自動生成する際、この「Webアプリ」をソースとして読み込ませてサーバー側でレンダリングさせる。

6. ベストプラクティス・用語集

用語 / コマンド 解説
Zod データの型定義スキーマ。Remotionでは props の型定義に推奨されていますが、必須ではありません。型安全性を高めるために使います。
AbsoluteFill <div style={{position: 'absolute', top: 0, left: 0, right: 0, bottom: 0}}> の代わり。画面いっぱいに配置するRemotion用コンポーネント。
Sequence <Sequence from={30}> のように使い、子要素の開始時間をずらすコンポーネント。動画編集のタイムライン操作にあたります。
Fast Refresh コードを保存すると、動画の再生位置を維持したまま瞬時に画面が更新される機能。
remotion render 【動画作成用】 手元のPCでMP4動画そのものを生成するコマンド。
remotion bundle 【Web公開・クラウド用】 動画プレイヤー機能を持ったWebページ一式を出力するコマンド。
