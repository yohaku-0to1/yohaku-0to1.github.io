Spring Simulator (バネ挙動)

spring() 関数のパラメータを調整して、理想の「弾み」を見つけましょう。

Mass (質量) 1.0

重さ。大きいほど動き出しが遅く、止まりにくい。

Damping (減衰) 10.0

抵抗。大きいほど振動が少なく、すぐ止まる。

Stiffness (剛性) 100

バネの硬さ。大きいほどキビキビ動く。

const animation = spring({ frame, fps, config: { mass: 1.0, damping: 10.0, stiffness: 100 } });
