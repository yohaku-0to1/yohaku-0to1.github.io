Remotion Animation Lab

Remotionのアニメーションパラメータを実験し、AIへの指示プロンプトを生成するツール。
Vibe Coding（AIとの対話開発）を加速させましょう。

Spring Simulator (バネ挙動)

spring() 関数のパラメータを調整して、理想の「弾み」を見つけましょう。

Mass (質量) 1.0

重さ。大きいほど動き出しが遅く、止まりにくい。

Damping (減衰) 10.0

抵抗。大きいほど振動が少なく、すぐ止まる。

Stiffness (剛性) 100

バネの硬さ。大きいほどキビキビ動く。

const animation = spring({ frame, fps, config: { mass: 1.0, damping: 10.0, stiffness: 100 } });

Interpolate Visualizer (補間)

interpolate() は「時間（フレーム）」を「値（不透明度や位置）」に変換します。

to
to
const opacity = interpolate( frame, [0, 30], [0, 1], { extrapolateRight: "clamp" } );

Easing Visualizer (緩急)

Easing 関数を使うと、動きに加速や減速をつけることができます。
Pro Tip: 登場には out（減速して止まる）、退場には in（加速して消える）を使うのが基本です。

Cubic Bezier Control Points (x1, y1, x2, y2)

import { Easing } from "remotion"; const value = interpolate(frame, [0, 30], [0, 100], { easing: Easing.linear });

Color Interpolation (色の変化)

interpolateColors() を使うと、色を滑らかに変化させることができます。

Preview
import { interpolateColors } from "remotion"; const color = interpolateColors( frame, [0, 30], ["#00ffff", "#ff00ff"] );
